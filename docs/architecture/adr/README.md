# Architecture Decision Records

ADR은 대안이 존재하고 이후 구현에 지속적인 영향을 주는 기술 결정을 기록한다.

파일 이름은 `NNNN-short-title.md` 형식을 사용한다. 상태는 `Proposed`, `Accepted`, `Superseded` 중 하나로 표시하고, 기존 결정을 바꾸면 이전 ADR을 삭제하지 않고 새 ADR에서 대체 관계를 남긴다.

각 ADR은 다음 내용을 포함한다.

1. Context
2. Decision
3. Alternatives
4. Consequences
5. References

현재 ADR:

- [`0001-apple-preview-provider.md`](0001-apple-preview-provider.md)
- [`0002-modular-monolith-stack.md`](0002-modular-monolith-stack.md)
